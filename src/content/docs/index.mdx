## Finding things

Search from the box in the header, or press <kbd>/</kbd>. Results are drawn from
every product at once, so you do not need to know which product owns an answer
before you look for it.

## Contributing

These docs are open source, and pull requests are welcome from anyone. If you spot
something wrong, out of date, or missing, you can fix it yourself.

Every page has an **Edit page** link at the foot that opens that page's Markdown
file directly in the GitHub editor. Change it, describe what you changed, and open
a pull request — no local setup needed for a typo or a clarification.
