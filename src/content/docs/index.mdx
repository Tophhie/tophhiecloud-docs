## Finding your way around

Every product has its own sidebar, so you only ever see the pages belonging to
whatever you are reading. To move between products, come back here.

Search works the other way round. It covers the whole knowledge base at once, so you
do not need to know which product owns an answer before you look for it. Use the box
in the header or press <kbd>/</kbd>.

## Contributing

These docs are open source, and pull requests are welcome from anyone. If you spot
something wrong or out of date, you can fix it yourself.

Every page has an **Edit page** link at the foot that opens that page's Markdown file
directly in the GitHub editor. Change it, describe what you changed, and open a pull
request. A typo or a clarification needs no local setup at all.
