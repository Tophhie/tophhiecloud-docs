## Product docs

Each product documented here has its own sidebar, so you only ever see the pages
belonging to whatever you are reading. Search works the other way round and covers
everything at once.

<CardGrid>
	{
		products.map((product) => (
			<Card title={product.name} icon={product.icon}>
				{(product.discontinued || product.internal) && (
					<p class="tc-card-badge">
						{product.discontinued && <Badge text="Discontinued" variant="danger" />}
						{product.internal && <Badge text="Internal" variant="caution" />}
					</p>
				)}

				{product.description}

				<p>
					<a href={product.href}>{product.linkText ?? 'Read the docs'}</a>
				</p>
			</Card>
		))
	}
</CardGrid>

More products will appear here as their documentation is written, either as a section
on this site or as a link out to wherever those docs already live.

## Finding your way around

To move between products, come back to this page. The Tophhie Cloud logo in the
header links here from anywhere on the site.

Search covers the whole knowledge base at once, so you do not need to know which
product owns an answer before you look for it. Use the box in the header or press
<kbd>/</kbd>.

## Contributing

These docs are open source, and pull requests are welcome from anyone. If you spot
something wrong or out of date, you can fix it yourself.

Every page has an **Edit page** link at the foot that opens that page's Markdown file
directly in the GitHub editor. Change it, describe what you changed, and open a pull
request. A typo or a clarification needs no local setup at all.
