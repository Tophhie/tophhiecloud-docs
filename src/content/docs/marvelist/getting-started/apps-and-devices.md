## Where Marvelist runs

| | |
| --- | --- |
| iPhone and iPad | Native app from the App Store |
| Apple Watch | Companion app and complications |
| Web | [app.marvelist.co.uk](https://app.marvelist.co.uk) in any modern browser |
| Widgets and Siri | Home screen widgets and Shortcuts on iOS |

The web app and the iOS app are the same product against the same data. Almost
everything is available in both, and the pages in these docs call out the few places
where they differ.

Apple-only features have [their own section](/marvelist/apple-devices/).

## Installing the web app

The web app is installable. In a browser that supports it you will be offered an install
prompt, which adds Marvelist to your dock or home screen and runs it in its own window
without browser chrome.

Installing is also what makes offline work reliably, so it is worth doing if you use the
web app regularly.

## Syncing

Changes sync automatically. There is no sync button and nothing to trigger.

If you have a list open in more than one place, changes made elsewhere appear without a
refresh. On a shared list you also see who else is looking at it. See
[Working together](/marvelist/sharing/working-together/).

## Working offline

Both the apps and the web work without a connection.

What you have already loaded stays readable, and changes you make are held locally and
sent when you reconnect. That includes creating tasks, ticking them off, and running a
whole [Focus plan](/marvelist/focus/focus-plans/) start to finish.

Two things worth knowing:

- **Something you have never opened may not be available offline.** The offline copy is
  built from what you have loaded, so a list you have never viewed on that device may not
  be there.
- **Changes sync in the order you made them**, and retrying is safe. If the same change
  is sent twice it is only applied once.

If a change seems not to have arrived on another device, check that the device that made
it has been online since. If it still looks wrong, see
[Troubleshooting](/marvelist/account/troubleshooting/).

## Early access

Two optional programmes, both under Settings.

**Join the Marvelist Beta** puts you on the TestFlight build, so you get features before
they ship. You need Apple's TestFlight app installed to take part. Beta builds are beta
builds: they see more bugs, which is the trade you are making.

**Become a Marvelist Insider** is the community side, for feedback and discussion rather
than pre-release builds. You can do either without the other.
