A Focus plan queues several tasks and runs them one after another, with breaks in between.
It is for a session where you know the four things you want to get through and would rather
not stop to decide between each one.

## Building a plan

Start a new plan and pick tasks. The picker works **across all your lists** in one sitting,
so you can gather from several lists without going back and forth. There is also an **Add
to Focus** shortcut on individual tasks.

For each task set a **focus length** in minutes, anywhere from 1 to 180. It defaults to your
configured focus duration.

You can reorder the queue, and set **mark complete when done** per task, so a task ticks
itself off when its block finishes.

## Plan options

| Option | Effect |
| --- | --- |
| **Skip breaks** | Runs tasks back to back with no break between them |
| **Hands-free** | Automatically starts the next focus block instead of waiting for you |

A live estimate shows the total time including breaks as you build, which is the quickest
way to find out that your four tasks are actually a three-hour session.

## How a plan runs

Each task runs as **one continuous focus block**, not several Pomodoros. Breaks happen
between tasks rather than inside them.

While a plan is running you see the current task, what is up next, and progress as "task X
of N". You can skip a task or stop the plan.

The plan survives a reload. Closing the tab and coming back picks up where you were.

## Adding tasks mid-plan

A running plan has an **Add tasks** control that reopens the picker and appends to the
queue, without disturbing what is already running or losing progress.

## Offline

Focus plans work fully offline. Building a plan, advancing through it, completing tasks and
stopping all work with no connection, and sync when you are back.

That includes the whole plan running end to end offline. Retries are safe, so a flaky
connection will not double-apply anything.
