Focus is Marvelist's timer for actually doing the work rather than organising it.

- [Pomodoro](/marvelist/focus/pomodoro/) covers the timer itself.
- [Focus plans](/marvelist/focus/focus-plans/) covers queuing several tasks to run
  through in one sitting.

Focus statistics and insights are a [Premium](/marvelist/premium/) feature. The timer and
plans are not.
