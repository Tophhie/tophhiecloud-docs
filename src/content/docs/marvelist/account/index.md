## Marvelist and Tophhie Cloud

Your Marvelist account is a Tophhie Cloud account. Some settings live in Marvelist, and some
live in your [Tophhie Cloud account](/account/) because they apply everywhere you use that
identity.

Where a setting lives in both, changing it in either place changes it everywhere.
