Attachments on tasks use cloud storage: **1 GB** on the free plan, **20 GB** on
[Premium](/marvelist/premium/).

## Seeing what is using space

The storage page breaks down your usage, and there is a file browser where you can open
files or delete them individually.

If you are near the limit, that browser is where to start. Photos and PDFs attached to
tasks you finished months ago are usually most of it.

## Reclaiming space

Storage can drift out of step with what you actually have. A deleted task can leave its file
behind, and a broken reference can point at a file that is no longer there.

The maintenance option reconciles this: it finds orphaned files and broken references and
reclaims the space.

Worth running if your usage looks higher than the files you can actually see. It is a tidy-up
of your own account, and it does not touch files that are still attached to something.

## If you run out

Nothing is deleted and nothing breaks. You cannot add new attachments until you free space or
upgrade.

Deleting attachments is the direct fix. Archiving a list does **not** free space, because the
files are still there. See
[Archiving and tidying up](/marvelist/lists-and-tasks/archiving-and-tidying-up/).
