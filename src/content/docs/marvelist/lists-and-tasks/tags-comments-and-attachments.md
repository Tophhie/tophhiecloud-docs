## Tags

Tags label tasks within a list. Create them from the list's **Manage Tags** menu, then
assign them to that list's tasks.

:::note[Tags belong to one list]
A tag is scoped to the list it was created on and can only be assigned to tasks in that
list. There is no account-wide tag shared across lists, so a "Waiting" tag on one list and
a "Waiting" tag on another are two separate tags that happen to share a name.
:::

That shapes what they are good for. A tag is a second axis *within* one list, not a way to
pull related work together from across your account. If you want a cross-list view, that is
what [smart lists](/marvelist/lists-and-tasks/smart-lists/) and search are for.

Tags work best kept few. Half a dozen meaningful ones on a busy list is useful; thirty is a
filing system you now have to maintain.

## Comments

Tasks have comment threads, and comments can be liked. On a
[shared list](/marvelist/sharing/) this is where the conversation about a task happens,
which keeps it attached to the work rather than scattered across messages.

Comments are visible to everyone the list is shared with. They are not private notes; use
the task's detail field for that.

## Attachments

Attach photos, PDFs and documents to a task. Attachments sync like everything else, so a
file added on your phone opens on the web.

Attachments count against your cloud storage: **1 GB** on the free plan and **20 GB** on
[Premium](/marvelist/premium/). You can see what is using space, and clear things out,
from [Cloud storage](/marvelist/account/cloud-storage/).

:::note
Deleting a task does not always free the space immediately. If your usage looks higher
than it should, the storage page has a reclaim step for files left behind by deleted
tasks.
:::
