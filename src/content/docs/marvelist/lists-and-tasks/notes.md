A notes list holds rich text instead of tickable items, so ideas and reference material
live in the same app as the work rather than in a separate notes app.

## Creating one

Choose **notes** rather than tasks when you create the list. The choice is made at list
level, so a list is one or the other.

## Writing

Notes support formatting, and they save as you write. There is no save button.

Notes are cross-compatible between iOS and the web, so something written on your phone
opens and edits correctly in a browser and the other way round.

## When to use a note rather than a task

A task is something to do. A note is something to keep.

Meeting notes, a packing list you reuse, reference details, a draft: those are notes. If
you find yourself writing a note that is really a list of things to do, it wants to be a
task list, because only tasks get due dates, reminders and smart lists.

## Sharing and protecting

Notes lists behave like task lists for everything else. They can be
[shared](/marvelist/sharing/), [locked](/marvelist/lists-and-tasks/locked-lists/),
[Vault-protected](/marvelist/lists-and-tasks/vaults/) and archived.
