## Co-organisers

An event can be shared with other Marvelist users so they can help organise it. They see
the guest list, the responses and the settings.

Worth doing for anything you are not hosting alone. The alternative is one person holding
the guest list and everyone else asking them for updates.

## Linking task lists

A task list can be linked to an event, which puts the planning next to the guest list.
Venue, catering, decorations, the running order: all the work an event needs that is not
about who is coming.

When you link a list you can also share it with event members who do not already have
access, so co-organisers get the planning list without a separate invitation.

## How this fits together

An event answers "who is coming". A linked task list answers "what needs doing". Keeping
them separate but connected means the guest list stays a guest list rather than turning
into a mixed pile of guests and to-dos.

See [Sharing a list](/marvelist/sharing/sharing-a-list/) for how list sharing works
generally.
