Create an event from the Events section. It needs a name; everything else can come later.

## The details

Add the date, time and location so they appear on the invitation guests see.

A **cover image** sets the tone of the RSVP page. It is the first thing a guest sees, and
it does more for the invitation than any other single field.

## Host name

By default the event is hosted in your name. You can set a **custom host name** instead,
which is what you want when the event is from a couple, a family or an organisation rather
than from you personally.

## Categories

Guests can be sorted into categories: sides of a family, teams, year groups, whatever fits.
Categories are for your organising rather than for guests, who never see them.

See [Guests and households](/marvelist/events/guests-and-households/).

## Events with several parts

If your event has distinct parts, and not everyone is invited to all of them, set those up
before you invite anyone. See [Event parts](/marvelist/events/event-parts/).

## Before you send invitations

Worth getting right first, because changing them after people have replied is messier:

- The date, time and location.
- Any [custom questions](/marvelist/events/questions-and-responses/) you want answered.
- [Event parts](/marvelist/events/event-parts/), if you need them.
- Whether guests get plus-ones, which is set per guest.

Then see [Invites and RSVP links](/marvelist/events/invites-and-rsvp-links/).
