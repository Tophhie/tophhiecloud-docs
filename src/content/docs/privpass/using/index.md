## First run

You set a master password. That single choice determines how well everything else holds up,
because of how PrivPass [derives keys](/privpass/security/encryption/) from it: there is no
work factor, so the password's own length is the whole defence.

Generate a long random one and record it somewhere safe outside PrivPass. There is no
recovery.
