Nothing here needs an account. Open a short link and it takes you where it points.

- [Following a link](/redirect-service/using/following-a-link/) covers what happens, and
  what each error means when it does not.
- [The index](/redirect-service/using/the-index/) covers the published list of links and
  how to search it.

## The short version

`https://aka.tophhie.cloud/<name>` sends you to the address stored against that name.
`aka.tophhie.dev` serves the same links, so either host works.

If a link does not work, it is usually one of three things: the name is wrong, the link has
been turned off, or you are going too fast and have hit the rate limit. Each returns a
different response, and [Following a link](/redirect-service/using/following-a-link/)
explains which is which.
