The Tophhie Cloud Redirect Service turns long URLs into short ones. A link like
`https://aka.tophhie.cloud/devops` sends whoever opens it to the full address behind it,
which is easier to say out loud, put on a slide, or print than the real thing.

| | |
| --- | --- |
| Short links | `https://aka.tophhie.cloud/<name>` |
| Also served on | `https://aka.tophhie.dev/<name>` |
| Public index | [aka.tophhie.cloud/index](https://aka.tophhie.cloud/index) |
| Managing links | Tophhie Cloud staff only |

## Two halves

The service is two separate pieces, and it helps to know which one you are dealing with.

The **public service** answers `aka.tophhie.cloud` and does the redirecting. Anyone can use
it. There is nothing to sign in to and nothing to install: you open a short link and it
sends you on.

The **admin portal** is where links are created and edited. It is internal to Tophhie
Cloud, sits behind a Microsoft Entra sign-in, and is not open for public sign-up. If you
want a short link created, ask rather than looking for a sign-up page.

## Why the links look like that

Short names are lowercase letters, numbers, hyphens and underscores. One segment only, so
`aka.tophhie.cloud/devops` works and `aka.tophhie.cloud/team/devops` does not.

That constraint is deliberate. A short link is meant to survive being read aloud, written
on a whiteboard and retyped from a photograph, and every extra character is another chance
to get it wrong.
