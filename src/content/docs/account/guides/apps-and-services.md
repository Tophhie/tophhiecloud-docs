The **Apps and services** page lists the Tophhie Cloud apps your account can use, and
when you last used each one.

Each entry shows whether it is active, when you last used it, how long you have had
access, and a link to open it.

## What this is not

This is a list of Tophhie Cloud's own apps and services. It is not a list of third-party
apps you have granted access to, and there is nothing to revoke here.

If you want to end access on a device rather than to an app, use
[sign out everywhere](/account/guides/password-and-sign-in-methods/#signing-out-everywhere)
on the Security page.

## If an app is missing

Not every Tophhie Cloud service appears here, and access to some is granted separately.
If you expect to see something and do not, email
[help@tophhie.cloud](mailto:help@tophhie.cloud).
